◆ csv_champ_suivant()

int csv_champ_suivant ( Un_lecteur_csv * lecteur)

Fonction qui permet d'avancer au champ suivant dans la ligne CSV. Cette fonction extrait le prochain champ et le place dans le tampon interne. Les espaces en début et fin de champ sont automatiquement supprimés.

Paramètres
lecteur: Pointeur vers le lecteur.
Renvoie
: 1 si un champ a été lu avec succès, 0 si nous sommes en fin de ligne ou s'il y a une erreur.

◆ csv_est_fini()

int csv_est_fini ( Un_lecteur_csv * lecteur)

Fonction qui vérifie si le lecteur a atteint la fin de la ligne. Permet de détecter si tous les champs ont bien été lus.

Paramètres
lecteur: Pointeur vers le lecteur.
Renvoie
: 1 si fin de ligne atteinte, 0 sinon.

◆ csv_lire_texte()

char * csv_lire_texte ( Un_lecteur_csv * lecteur,
size_t max_size )

Fonction de récupèration du champ courant comme chaîne de caractères. Le champ est déjà nettoyé (espaces en début/fin enlevés) par csv_champ_suivant().

ATTENTION : Le pointeur retourné pointe vers le tampon interne du lecteur. S'il est libéré, il sera écrasé au prochain appel de csv_champ_suivant().

Paramètres
lecteur: Pointeur vers le lecteur.
max_size: Taille maximale attendue pour ce champ (incluant le '\0').
Renvoie
: Pointeur vers le champ dans le tampon interne, ou NULL si le champ dépasse max_size.
