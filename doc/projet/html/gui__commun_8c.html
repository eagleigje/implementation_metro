TTF_Font * gui_charger_police ( int taille)

Fonction qui charge une police TrueType (TTF) à partir de chemins connus du système d'exploitation. Une police locale dans le dossier fonts/ est utilisée en dernier recours.

Paramètres
taille: Taille en points de la police à charger.
Renvoie
: Un pointeur vers la police chargée, ou NULL si aucune n'est disponible.
