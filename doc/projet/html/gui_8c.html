enum Ecran

Type énuméré représentant les différents écrans de l'application. ECRAN_MENU : Écran d'accueil avec les options de navigation. ECRAN_PLAN : Écran principal affichant le plan du métro.

enum Mode

Type énuméré représentant les modes d'interaction disponibles sur le plan. MODE_SELECTION : Permet de sélectionner des stations individuellement. MODE_CHEMIN : Permet de calculer le plus court chemin entre deux stations.
