◆ cherche_chemin()

Un_elem * cherche_chemin ( Un_truc * sta_arr)

Fonction qui reconstruit le chemin depuis la station de départ jusqu'à une station d'arrivée, en remontant les connexions stockées dans con_pcc.

Cette fonction doit être appelée APRÈS l'exécution de dijkstra(). Elle utilise le champ con_pcc de chaque station pour remonter de l'arrivée vers le départ.

Paramètres
sta_arr: La station d'arrivée dont on veut reconstituer le chemin.
Renvoie
: Une liste chaînée de connexions (Un_elem) représentant le chemin à emprunter, dans l'ordre (de la station de départ vers la station d'arrivée), ou NULL si aucun chemin n'existe ou si la station est invalide.

void dijkstra ( Un_elem * liste_sta,
Un_truc * sta_dep )

Fonction qui implémente l'algorithme de Dijkstra pour calculer le plus court chemin depuis une station de départ vers toutes les autres stations du réseau.

L'algorithme prend en compte :

  • Le temps de parcours de chaque connexion (stocké dans user_val de la connexion)
  • Le temps d'arrêt à chaque station
  • Le temps de correspondance lorsqu'on change de ligne

Après exécution, chaque station contient dans user_val le temps minimal pour l'atteindre depuis la station de départ, et dans con_pcc la dernière connexion empruntée pour atteindre cette station (permettant de reconstituer le chemin).

Paramètres
liste_sta: La liste de toutes les stations du réseau.
sta_dep: La station de départ du calcul.
