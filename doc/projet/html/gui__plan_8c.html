◆ gui_dessiner_plan()

void gui_dessiner_plan ( Etat_affichage * app,
int largeur,
int hauteur )

Fonction qui dessine l'écran plan avec grille et panneau d'information. L'ordre de rendu est important pour garder les éléments lisibles : fond -> grille -> connexions -> stations -> surbrillances -> panneaux.

Paramètres
app: État global de l'application graphique.
largeur: Largeur de la fenêtre.
hauteur: Hauteur de la fenêtre.

◆ gui_plan_gerer_clic()

int x,
int y )

Fonction qui gère les clics souris sur le plan. La station la plus proche est sélectionnée, puis utilisée comme départ/arrivée si l'on est en mode chemin.

x: Position X du clic.
